# User data request process (draft)

Operational contact: `recallplus.website@gmail.com` (also `[PRIVACY EMAIL]` / `[SUPPORT EMAIL]` placeholders for final policies)

## Self-serve (in product)

| Right | How |
| --- | --- |
| Access / portability (study data) | Settings → Download backup |
| Correction (display name / subjects) | Profile / onboarding edit flows |
| Erasure | Settings → Delete account (confirmation `DELETE MY ACCOUNT`) |
| Contact / grievance | Contact panel / email |

## Assisted requests

1. User emails from the address on the account.
2. Operator verifies identity without phishing for passwords.
3. Fulfil or explain limitation within a documented target of **30 days** where feasible.
4. Log request meta (date, type, outcome) — not full message bodies — in a private tracker.

## Lawyer review required

- Formal DPDP Data Principal rights wording and timelines once substantive obligations apply.
- Child / guardian request handling for users under 18.
