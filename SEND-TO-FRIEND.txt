RECALL+ — Setup instructions
==============================

Recall+ now requires Supabase authentication and database-backed generation
limits. Use Node.js 22 or newer, open the folder containing package.json, and
follow README.md from “Install and configure locally”.

Before running npm run dev:

1. Copy .env.example to .env.
2. Add the public Supabase URL and anon key.
3. Add the server-only Supabase service-role key.
4. Add the server-only NVIDIA NIM key and verified GLM-5.2 model ID.
5. Apply the checked-in Supabase migration.

Never share or commit .env. The NVIDIA key and Supabase service-role key must
never use a VITE_ prefix.
